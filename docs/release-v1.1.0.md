# URAW Recorder v1.1.0

这版在录制模式下新增实时输入监听，为增益旋钮增加滚轮微调并改进频谱与 VU 表显示，同时修复了侦听、录制收尾与模式切换中的几处状态问题。

## 录制模式实时监听

- 底栏新增录制监听开关，开启后在右侧显示监听音量旋钮。在待机、录制和暂停期间均可随时开关监听并调节监听音量。
- 监听信号取自频响校准与输入软件增益之后，经共享模式 WASAPI 输出至 Windows 默认多媒体播放设备。默认播放设备切换或输出流异常时，程序会自动重连。
- 播放设备打开失败或连续重连失败时，程序会自动关闭监听并弹窗提示，不中断正在进行的录音与文件保存。
- 监听开关状态不保存，每次启动时默认关闭，以免误开外放产生啸叫。程序仅保存监听音量，首次使用默认为 `−30.0 dB`。
- 同时启用频响校准与录制监听时，若当前校准存在处理延迟，每次运行首次触发会弹窗告知固定监听延迟的毫秒数。
- 切换至侦听模式时会自动关闭录制监听，退出程序时会停止监听并释放播放设备。

## 旋钮与仪表显示

- 监听音量旋钮的操作方式与输入软件增益旋钮相同，非 `0 dB` 时数值仍以灰色显示，双击旋钮可归零至 `0 dB`。左侧输入软件增益数值变宽或展开输入框时，右侧监听控件会平滑右移让出空间。
- 输入软件增益与监听音量旋钮新增鼠标滚轮微调。数值处于 `0 dB` 时锁定滚轮，将其调离 `0 dB` 后解锁，常规每格步进 `0.5 dB`，按住 `Shift` 为 `0.1 dB`。
- 频谱图曲线下方的渐变填充延伸至 `-96 dBFS` 底轴，高电平时曲线下方不再留白。
- VU 指针与频谱图在信号出现、停止及切换模式时会平滑起落。从频谱视图切走后，在无信号状态下切回不再短暂显示旧频谱。

## 稳定性与界面修复

- 正在侦听或等待音频播放期间，禁用顶部工作模式选择框。模式切换期间禁用监听按钮。
- 暂停录制后若输入设备停止提供音频，等待尾音的时长上限为 30 秒，超时后报错并收尾，不再无限期等待。
- 压缩录音未写入有效音频即失败时，自动清理 0 字节空文件与临时编码文件，且不生成校准摘要。丢弃录音时不再写入多余的校准摘要目录。
- 切换至侦听模式后，此前未弹出的独占提示、RAW 降级询问和输入设备查询不再在侦听界面触发。侦听模式下的底栏状态与峰值重置不再受录制状态或停止竞态影响，关闭窗口时会取消未完成的按钮动画。

## 下载与运行

在 Windows x64 上下载并运行 `URAW Recorder v1.1.0.exe`。程序内置 .NET、WinUI 和音频编码器，支持 WAV、FLAC 和 MP3 录制。首次运行时会提取所需文件。

`SHA256SUMS-v1.1.0.txt` 用于校验发行附件。`URAW-Recorder-v1.1.0-FFmpeg-source.zip` 提供随附编码器的源码、构建脚本和许可文件。
