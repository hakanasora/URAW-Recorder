# URAW Recorder v1.1.0

本次更新在录制模式下新增实时输入监听，为旋钮增加滚轮调节并改进频谱与 VU 表显示，同时修复了模式切换、侦听状态与录音收尾中的几处问题。

## 录制模式实时监听

- 点击底栏带耳机图标的监听按钮即可开启录制监听，右侧会展开监听音量旋钮。在待机试音、录制和暂停期间均可随时开关监听并调节音量，直接确认收音效果。
- 监听信号经过与录音相同的频响校准和输入软件增益处理，可用来判断收音音色。监听音量旋钮只调节监听回放响度，不会改变录音文件电平与仪表读数。
- 监听声音输出至 Windows 默认播放设备。当默认播放设备随系统设置或插拔耳机变更时，监听会自动切换到新设备。若播放设备断开或无法使用，程序会关闭监听并弹窗提示，不会中断正在进行的录音。
- 为避免外放引起啸叫，每次启动程序时监听开关默认关闭，切换至侦听模式时也会自动关闭录制监听。无历史设置时监听音量默认为 `−30.0 dB`，调整后会在后续启动时保留。
- 开启麦克风频响校准后，实时校准处理会引入固定的监听延迟。若所用校准存在处理延迟，每次运行仅在首次同时启用校准与监听时弹窗告知具体的延迟毫秒数，不会在每次开关监听时重复弹出。该延迟仅影响实时监听，不会改变录音文件与校准精度。若试音时需要更低延迟，可在设置中临时禁用校准。

## 操作手感与画面优化

- 监听音量旋钮支持上下拖拽、点击数值输入、方向键调整及双击归零至 `0 dB`，操作方式与输入软件增益旋钮一致。即使数值不为 `0 dB`，监听音量仍以灰色显示，以便与输入软件增益区分。左侧输入软件增益数值变宽或展开输入框时，右侧的监听按钮与旋钮会平滑右移让出空间。
- 输入软件增益与监听音量旋钮新增鼠标滚轮调节，每格步进 `0.5 dB`，按住 `Shift` 时每格 `0.1 dB`。数值为 `0 dB` 时滚轮保持锁定，防止误触改变默认电平。通过拖拽、方向键或输入数值离开 `0 dB` 后，即可使用滚轮微调。
- 频谱图曲线下方的渐变填充延伸至底部 `-96 dBFS` 刻度线，高电平时曲线下方不再留白。
- VU 表指针与频谱图在音频信号出现、停止及切换工作模式时改为平滑升降，不再瞬间跳变或突然归零。在无信号状态下从电平或音高视图切回频谱图时，不再短暂闪现旧画面。

## 稳定性修复

- 正在侦听或等待播放音频期间，顶部工作模式菜单保持不可切换，需先停止侦听再切换模式。
- 修复暂停录制时输入设备停止提供音频导致一直等待收尾的问题。等待超过 30 秒仍无新音频输入时，程序会提示错误并完成本次录音收尾。
- 修复压缩录音未写入音频便失败时残留空文件的问题。提前失败时会自动清理 0 字节文件与临时编码文件，且不再为失败的空文件或已丢弃的录音生成校准摘要文件。
- 切换至侦听模式后，此前未弹出的录制提示不会再在侦听界面出现，侦听期间的按钮状态与峰值重置也不再受录制状态干扰。

## 下载与运行

在 Windows x64 上下载并运行 `URAW Recorder v1.1.0.exe`。程序内置 .NET、WinUI 和音频编码器，支持 WAV、FLAC 和 MP3 录制。首次运行时会提取所需文件。

`SHA256SUMS-v1.1.0.txt` 用于校验发行附件。`URAW-Recorder-v1.1.0-FFmpeg-source.zip` 提供随附编码器的源码、构建脚本和许可文件。
