# 独立设置抽屉

2026-10-26：替换仍会触发标题栏闪烁的单窗伸缩方案。

## 窗口与视觉

- 主客户区始终为 820×416 DIP，打开和关闭设置不再调用主窗 MoveAndResize。仅初始化和 DPI 变化更新主窗的物理像素尺寸。
- 设置使用同一 UI 线程上的原生 WinUI Window，宽 264 DIP，去除系统边框、标题栏和独立任务切换入口，通过原生 owner 关系隶属主窗。不是第二个进程，也没有第二套采集或设置模型。
- 面板背景保持 #161617。顶部留出与主窗 32 DIP 标题区等高的空白，使菜单内容与主工作区对齐。
- 附属窗口大小固定；280 ms 三次 ease-out 移动 XAML Composition visual 的 Translation，同时更新附属 HWND 的矩形区域，形成从主窗左边缘向外抽出的效果。关闭反向收回，快速反向操作从当前进度开始。原生区域裁切防止 Show 时先露出整块空背景；不逐帧缩放主窗口或附属窗口。
- 禁用系统动画时直接到达终态。仅展开过程中订阅合成事件，停止后解绑；不改变音频分析和写盘频率。
- 左侧当前屏幕工作区不足以容纳完整面板时，复用同一菜单作为覆盖抽屉，不移动主窗。已打开附属面板随主窗移动进入屏幕左边缘时也转为覆盖，直到下一次重新打开再评估。
- 主窗移动和 DPI 变化更新附属窗位置；最小化时隐藏，恢复后显示；退出时释放附属窗口。Esc 或面板关闭按钮收回，动画结束后归还菜单按钮焦点。
- 原有输入、文件、下拉框、校准入口及音频命令保持共用；没有修改服务接口。

## 核对范围

本轮仅必要编译、发布和 Git 差异检查；没有启动 EXE、使用 Computer Use 或占用麦克风。不能以编译成功宣称闪烁已经通过视觉验收。

请实窗协同复测：

1. 左侧留有空间，反复打开和关闭设置，并快速反向点击。主窗位置、标题栏宽度及仪表布局应保持不变；面板不应先闪出整块矩形。
2. 主窗靠近屏幕左侧，打开菜单应覆盖而不推动主窗；菜单内输入／文件切换、下拉选择、路径编辑和校准对话框应可操作。
3. 面板打开时移动主窗、最小化／恢复和跨不同缩放屏幕；核对贴合位置、焦点及任务栏只显示主窗。
4. 开关设置不应停止共享监看或录音。关闭整个程序应同时关闭附属面板，并沿用既有录音收尾行为。

若存在原生表面裁切、跨屏焦点或驱动特定的显示异常，结合实窗录屏和日志继续修正；当前没有实测帧率或零闪烁保证。
