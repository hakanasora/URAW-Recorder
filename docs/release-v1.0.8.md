# URAW Recorder v1.0.8

这版修复了暂停录制、切换音源和关闭程序时的几处问题。

## 录制与保存

- 输入暂时没有数据时，按下暂停后会显示「正在暂停」。输入恢复后会自动完成暂停，等待期间仍可停止录制。
- 录音收尾时遇到驱动故障，会保留原始错误和部分录音的路径。写入队列满时，会写完此前已接收的连续音频。
- 切换输入设备失败时，界面会显示实际的采集状态。上一个设备的 RAW 降级回复不会应用到新设备。
- 校准设置保存失败时，当前校准和历史峰值会保留。Windows 输入增益停止更新时，可手动刷新输入设备以重新连接。

## 侦听与界面

- 刷新侦听来源时，保留等待期间新选中的应用或输出设备。收到新的音频数据后，过期的超时检查不会把仪表切回等待状态。
- 切换录制与侦听时，先停止旧音源。新音源初始化失败后，可在当前模式刷新重试。
- 快速开关设置侧栏时，动画会从当前位置反向播放，收起后将键盘焦点交还给菜单按钮。退出时会取消排队的普通弹窗，必要时仍会显示录音收尾错误。

## 下载与运行

在 Windows x64 上下载并运行 `URAW Recorder v1.0.8.exe`。程序内置 .NET、WinUI 和音频编码器，支持 WAV、FLAC 和 MP3 录制。首次运行时会提取所需文件。

`SHA256SUMS-v1.0.8.txt` 用于校验发行附件。`URAW-Recorder-v1.0.8-FFmpeg-source.zip` 提供随附编码器的源码、构建脚本和许可文件。
