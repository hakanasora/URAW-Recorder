## 本方案的方向

保留深色、克制、仪器感、琥珀双 VU、突出数字和紧凑录音动作。把当前界面推进为一套一致的规则：稳定主工作面、可退让的配置检查器、独立计时与操作区；从成熟案例借鉴其任务组织、状态模型和组件细节。

默认方案只给一套。Segoe UI Variable／Bahnschrift 数字候选的比较属于阶段二的字体实验，不另造三套互不相干的产品风格。

## 最需要先看见的变化

用户已明确授权：只保留产品性格，其余布局与交互可以大胆重做。因此本方案不是把 HTML 换成 XAML 的保守移植。

1. 三种监看能力改为直接可见的紧凑选择条；配置入口移到头部，底栏只管理会话和增益。
2. INPUT／FILE 改为检查器两页，FILE 不再藏在长滚动末尾；默认 416 DIP 高窗口可看到当前页全部设置。
3. 录制与停止固定在右侧同一槽位，取消飞移；继续／停止仍在固定 145 DIP 组内交换宽度。
4. 当前 RMS 先读；历史 PEAK 放到下面，当前过载时显示带文字的提示，与当前读数放在一起，消除「当前灯」与「历史红字」的混淆。
5. 统一中英文、图表和数字的文字角色。三项有依据的颜色细化是：侧栏标签 #A1A1A6、占位字 #BDBDC2、白字录制底 #D3222B；停止／过载仍保留 #FF3037。

这些是研究提出的新版设计决定，不伪装成已经确认过的旧规格。阶段二按这一套方案实现并进入原生窗体评审。本研究不等于已经验证 WinUI 的字体和图形实际渲染。
