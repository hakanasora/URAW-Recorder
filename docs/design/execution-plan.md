# Portable Recorder：原生窗体成熟度提升明细执行方案

日期：2026-10-24（Asia/Shanghai）｜版本：研究规格 v1.2｜状态：第一阶段完成，第二阶段未开始。

基线为 `main@742c85e`，本研究位于 `design/native-ui-maturity-research`。所有尺寸均为 **DIP**，颜色均为 **sRGB HEX**，动效时间为 ms。这里给出的精确数值是针对本项目的设计决定，不是从 Apple 或其他产品测得的官方标准。

## 1. 原点、目标与边界

**原点**：这是一个面向多种输入设备、稍具专业性和进阶能力的便携录音工具。UMIK-1 只是可用输入之一，不是产品命名或设计前提。深色、克制、仪器感；琥珀色 VU 具有识别度；数字容易读取；录音动作集中且紧凑。成熟度来自同一套规则贯穿结构、状态和视觉。

**必须保留的是产品性格**：深色、克制、仪器感、琥珀 VU、清楚数字、围绕录音的紧凑操作。用户已明确授权：只要保留这一原点，结构和交互均可大胆重做。现有布局、菜单形式和按钮飞移不是不可触碰的约束。

**本方案主动重做五处结构**：三种监看从下拉菜单变为直接可见的三段选择；检查器 INPUT／FILE 分页，文件设置不再藏在长滚动末尾；配置入口移到头部；录制／停止固定右侧，取消飞移；历史 PEAK 移到主读数下面，当前过载灯则与当前读数放在一起。保留左数字右双 VU，是综合对比后的选择，不是照搬限制。

这五处作为一套方向实施，而非给用户留下五个未决选项。深层分工是：头部决定看什么／配置什么，中央显示当前信号，底部管理本次会话。更换字体、颜色、形状和动效均服从这套分工。

**第二阶段交付物**：真正的 C#＋WinUI 3 原生窗体，XAML 控件＋Win2D 仪表；使用模拟数据。保留未来替换数据来源的边界，不实现麦克风采集、校准滤波、FFT／音高算法、编码或音频写盘。文件选择仅取得本地路径和列表元数据，不读取校准内容。

不加入多轨、时间线、EQ 节点、波形编辑器、转录或回放。截图中的聊天按钮、右下角宿主调参齿轮、展开和更多按钮不是产品组成，不移植进窗体。

## 3. 原生窗口与布局

### 3.1 窗口尺寸与系统行为

- 默认**客户区**为 820 × 416；其中自定义标题栏 32，应用工作区 820 × 384。系统外边框不计入此数值。
- 最小客户区同为 820 × 416。阶段二先面向本机 Windows 11 x64；正式最低 Windows 版本不在本轮冻结。
- 使用原生 TitleBar／AppWindow，保留 Windows 的拖动、系统菜单、最小化、最大化、关闭和 Snap。窗口按钮由系统管理，按系统左右 inset 留空，不画 macOS 红黄绿按钮。
- 标题暂用 `Portable Recorder · UI Preview`（工作名称，正式品牌名另定），12 DIP，次要色；标题栏背景 `#1B1B1B`。可点击控件不得属于拖动命中区。
- 客户区允许放大。主工作区超过 820 时，左读数宽度保持，右侧 VU 对作为整体在剩余空间居中；图表利用新增面积。高度新增部分给监看区，顶栏／底栏保持固定高度。
- 不对整个窗口套 Viewbox；DIP 在 XAML 与 Win2D 中一致。跨显示器切换时让系统处理缩放，重新创建 DPI 相关画布缓存。

### 3.3 检查器开关与窄工作区

- 检查器宽 264，位于工作区左侧（标题栏下）。主体主工作区保持至少 820 宽。
- 普通未最大化窗口且显示器工作区能容纳 1084 × 416 客户区时，展开后增加窗口宽度 264，主工作区右移 264，自身尺寸不变。尽量维持窗口左上角；如右边越界，整体向左移至工作区内。
- 最大化或工作区不足时使用 264 宽覆盖检查器，**不挤小主工作区**。主区添加黑色 24% 遮罩；点击遮罩只关闭面板，不透传录制点击。
- 收起仅撤回本次自动增加的宽度。如果用户在展开后主动调整过窗口，不擅自恢复旧窗口尺寸，保留当前大小。
- 最大化／还原和 DPI 改变时重算 inline／overlay，保留开关状态、当前滚动位置和焦点。
- 检查器分 INPUT／FILE 两页，默认尺寸下当前页全部字段可见；仅在文字放大或异常提示增高后纵向滚动。页签和关闭按钮固定顶区，录制区不随它滚动。面板关闭时焦点回到头部开关；overlay 期间键盘焦点限定于面板，Esc 收起。
- 若系统可用工作区本身小于最小客户区，先保证系统可移动和关闭窗口；首版不假装支持手机宽度，也不将 820 工作面硬缩到 320。

### 3.4 文字放大的确定重排规则

上表是文字比例 `s=1` 的坐标，不是给所有字号强行固定同一矩形。`s` 是系统文字缩放比例，与显示器 DPI 缩放分别处理。XAML 文字由系统缩放，Win2D 文字显式采用相同 `s` 一次；下列公式只安排布局，不再次放大已经缩放过的 XAML 字号。

- 读数列宽 `R=ceil(200s)`；读数内容高 `B=ceil(114s+max(24s,28))`，包含数字、单位、间距和历史行。单位与过载状态同行按比例分配，不将放大的字塞进原 74 宽槽。
- 双 VU 画布仍为 536 × 159 的整对；下方标签随文字放大，整块高 `V=ceil(172+16s)`。普通 `s=1` 为 188，`s=1.5` 为 196。
- 主区宽 `W` 达到 `28+R+28+536+28` 时左右并排，监看区所需高 `max(236,B+48,V+48)`。例如 150% 文字需 920 宽才能并排；这不是 150% 显示 DPI 所要求的逻辑宽度。
- `s>1` 且 `W` 小于该阈值时，改为读数在上、双 VU 在下；读数仍左对齐 28，双 VU 水平居中，内容总高 `24+B+24+V+24`。150% 文字、820 宽时为 475；不横向压缩数字或缩小表盘。监看内容超过当前可用高度时，仅监看区纵向滚动，顶栏和录制区常驻。
- 顶部模式选择器宽 `ceil(240s)`、高 `ceil(36s)`，项宽和内边距按比例分配；顶栏高 `max(64,ceil(36s)+28)`。输入名称使用到选择器左缘前 16 为止的剩余宽度，尾部省略并提供完整名称提示；不足 48 时只隐藏名称，配置入口始终保留。
- 底栏增益热区宽 `ceil(88s)`，时钟槽宽 `ceil(240s)`，宽／窄动作宽分别 `ceil(100s)`／`ceil(42s)`，按钮高 `ceil(42s)`，间隙仍 3。只有时钟两侧与增益／动作组均至少相隔 16 时使用单行，否则变为两行：第一行增益在左、计时居中；第二行动作组靠右。第一行高 `max(44,ceil(60s))`，第二行高 `ceil(42s)`，上下内边距各 12，行间 8；单行高为 `max(84,ceil(60s)+24)`。录制开始后不因计时出现再临时改变行数，待机也按完整槽位计算。
- 检查器宽保持 264，标签及字段按内容增高、允许提示换行，当前页可纵向滚动；不要求 150% 文字时 FILE 仍不滚动。顶区高 `max(48,ceil(28s)+20)`，页签宽仍 84、高 `ceil(28s)`，避免放大文字穿出顶区。面板使用覆盖模式。原生窗口尽量增高到所需高度并限制在工作区内；不足的高度由监看／检查器各自滚动承接，不能挤掉系统窗口按钮或底栏。

默认 100% 文字尺寸和 820 × 416 布局不变。以上规则优先于固定坐标表，解决大字裁切；阶段二仍需核查真实字形度量和焦点可见性。

### 4.2 为什么有三项细化

使用 W3C 的 sRGB 相对亮度公式计算原始色值（非截图取样）：

| 组合 | 对比度 | 方案决定 |
|---|---:|---|
| 原灰 `#86868B`／显示 `#1B1B1B` | 4.75:1 | 保留显示区灰 |
| 原灰／侧栏 `#252527` | 4.22:1 | 小标签提亮为 `#A1A1A6`，5.95:1 |
| 原灰／项目框 `#49494D` | 2.47:1 | 框内占位改为 `#BDBDC2`，4.79:1；值仍为主白 |
| 白 `#F5F5F7`／原红 `#FF3037` | 3.37:1 | 14 DIP 白字录制底收深为 `#D3222B`，4.78:1 |
| 底栏灰 `#6E6E73`／`#0E0E0E` | 3.81:1 | 留给非文字图标，不用于小号操作文字 |
| 蓝 `#0387FF`／控制底 | 5.44:1 | 保留 |

这三项是本方案明确提出的改进，**不代表用户此前已确认这些新数值**；阶段二按本方案进入原生效果评审。录制仍有红色性格，停止和过载仍使用用户选定的明亮红。不得为「提亮」把正常 PEAK 又改回白色。这里以 4.5:1 普通文字、3:1 大字／必要非文字作为设计基准，不据此宣称整个样机已获可访问性认证。[W3C 说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

系统高对比模式优先使用系统资源，替换表面、文字和焦点色；语义同时由图标和文字承载，不能只依赖红／灰／蓝。

## 5. 字体与文字角色

本机只读核查确认：Segoe UI Variable、Segoe UI、Microsoft YaHei UI、Bahnschrift、Consolas 存在。`SegUIVar.ttf` 的 family 名确为 `Segoe UI Variable`；不硬编码不存在的 Text／Display 子家族。

默认英文字体 `Segoe UI Variable`；中文标签 `Microsoft YaHei UI`。混排文件名由统一文本组件按中／英字符建立 Run；组合标记、符号和 Emoji 使用系统回退，不拆开字素簇。不提取或打包 Apple 系统字体。图表文字从同一份文字资源取值，禁止重新写死另一套字体。

| 角色 | DIP / 行高 | 字重 | 字距 | 色彩／说明 |
|---|---|---|---|---|
| 大电平读数 | 69 / 72 | Bold 700 | −0.02 em | 主白，等宽数字；短负号另绘 |
| 音名 | 69 / 72 | Regular 400 | −0.02 em | 主白；八度 36、对齐音名字母基线 |
| Hz 数值 | 20 / 26 | Regular 400 | 0 | 主白，Hz 为 12 的次要字 |
| 时钟 | 32 / 40 | Regular 400 | −0.01 em | 全部数字同色同字号，等宽数字 |
| 主操作 | 14 / 20 | Semibold 600 | 0 | 录制／继续／停止；不扩大按钮高度 |

XAML `CharacterSpacing` 使用千分之一 em：−20、−10、120 对应上表。动态数字启用 `Typography.NumeralAlignment=Tabular`、`NumeralStyle=Lining`；阶段二用 `11:11.11` 和 `88:88.88` 实际测宽，属性存在不等于字体已表现正确。Win2D 文本使用同一字体与 OpenType 数字特征。

短负号在 69 DIP 下为 18 × 5；与数字间距 4，位于数字行光学中部，默认中心 y=40（相对 72 高行）。它随文字缩放同比例变化，辅助技术读完整带符号数值。禁止用 ScaleX 横向压扁数字。

**字体实验只在原生窗体做**：开发评审入口 `Ctrl+Alt+T`，比较 A=Segoe UI Variable 数字、B=Bahnschrift 数字；中文、布局、颜色完全相同，避免变量混杂。Consolas 仅作为等宽诊断样本，不作为默认产品风格。字体入口不出现在普通主界面。

系统文字放大时保持启用文字缩放：读数／底栏所需高度可按内容增长；开启检查器覆盖模式以保住主区；不裁掉字、不通过全窗口缩小抵消用户设置。阶段二需实看 100%、125%、150%、200% 显示缩放以及 150% 文字放大。

## 6. 组件的完整视觉与交互规格

### 6.1 头部：配置来源与三种监看模式

将原来的单个下拉按钮替换为 240 × 36 的紧凑三段选择器，标签为「电平／频谱／音高」。三种能力直接可见，当前所在模式明确，不再需要先打开菜单。三者是同一录音任务的不同观察方式，不是三个独立程序。

使用真正的 WinUI SelectorBar＋SelectorBarItem。底槽 SelectorSurface，外圆角 4，无描边；内边距 4；每项 76 × 28，项间 2，正好 240 宽。选中项 SelectorSelected，内圆角 3，文字主白；未选项文字 DisplaySecondary；Hover 用 SelectorHover，Pressed 用 #303033。焦点环独立于选中底面。

短标签的可访问名称／ToolTip 分别为「输出电平／实时频谱／音高与频率」，与主区实际含义一致。

左右键切换、Home／End 和原生选择项可访问语义保留。模式切换只换当前可视化，不重置时钟、信号、增益、历史峰值或录制状态。不做横向整屏滑动，使用 100 ms 透明度过渡；减少动态效果直接切换。

左侧配置开关使用 18 的三横线图标和 40 × 44 热区，Normal 为 DisplaySecondary，Hover 主白＋#29292C 底，Pressed 为 #101012，展开态为主白。AutomationName「输入与文件设置」，ToolTip 同名。其右侧显示当前选中输入设备的 FriendlyName，13 DIP，主白，不硬编码任何型号。图标和文字共享 y=70 的光学中心线：40 × 44 按钮在 (28,48)，18 × 12 图形以 (48,70) 为中心；文字在 (76,60) 的 180 × 20 槽中。原生实现使用同一 Grid 行，不分别手写顶部偏移；以实际字体的字形边界校核光学中心，不能只看外层矩形对齐。预览图也按字形边界居中绘制。头部是客户端控件区，不参与窗口拖动。

设备名从同一 SelectedInputDevice 状态派生，与 INPUT 选择同步。纯 UI 阶段以可切换的模拟设备演示；服务接入后使用真实设备友好名称，并响应当前设备切换、默认设备解析变化和拔出。未选择显示「选择输入设备」，当前设备丢失显示「输入设备已断开」；插入其他设备不能静默替换已手选设备。长名称尾部省略，完整名可通过提示查看。

### 6.2 两页检查器、字段与文件设置

- 检查器宽 264，固定顶区高 48。INPUT／FILE 是同一面板中的两个可见页签，区分两类配置；不再把 FILE 堆在滚动末尾，也不重复放第二层大标题。
- 页签区域 x=20、y=12，176 × 28；**容器内边距为 0**，每项 84 × 28、间隙 8，即 84＋8＋84＝176。英文 12 DIP／600，选中主白、未选 InspectorLabel；只沿用主模式的状态颜色和圆角，不继承其 4 DIP 内边距。关闭热区 32 × 32，右 24，上 8；关闭图标 14，Normal CloseInk、Hover 主白＋#343437。
- 两页均用原生 SelectorBar。关闭再打开恢复上次页；两页分别保留值、焦点及滚动位置。切 FILE 不改变主区监看模式。
- 顶区下方唯一内容区左右内边距 24，净宽 216，最小可见高 336。字段标签图标 16，与文字间 8；标签高 20，标签至框 8，字段高 36，组间 24。字段圆角 3、无描边，左右内边距 12，箭头 14、右 10、垂直居中。
- INPUT 页从内容区 y=16 开始放设备组，y=104 放校准组，y=180／208 放添加／管理链接；总高度约 252，默认窗口无需滚动。标签用 InspectorLabel，值主白，链接 13 DIP／Link 色，悬停下划线，不带省略号。
- FILE 页从 y=16 放路径组，y=104 放格式组，y=192 放条件品质组，y=264 放两行提示；加底部 24 后总高不超过 320，默认 336 高内容区内全部可见。
- 输入设备为两个模拟候选；校准初始两份文件名加「不使用校准」。原生样机不继承聊天预览的 16 项元数据限制；管理列表使用 ListView 虚拟化。
- 路径行：172 宽编辑框＋8 间距＋36 浏览按钮。**两者各自完整保留四个 3 DIP 圆角**，相邻边也圆；不画贯穿两者的整块底面，不共享外轮廓，不继承录制动作组的内侧直角。原生 FolderPicker 返回完整路径，取消不改原值；不伪造前缀，不验证或创建输出目录。异常在框下显示可理解短提示，不弹技术堆栈。
- 长路径编辑时水平滚动，非编辑时尾部省略＋完整 ToolTip；文件名可包含中文和空格，不挤压浏览按钮。
- 默认 WAV；FLAC／MP3 分别保留 0／5／8（默认 5）和 320／256／192／128 kbps（默认 320）。WAV 隐藏品质；FLAC 注明等级只影响体积与耗时，始终无损。条件行在 FILE 页内部显露，不影响 INPUT 或主区。
- TXT 添加使用原生多选 FileOpenPicker，只保存路径／名称，同一完整路径更新；不读取内容、不应用滤波。管理弹窗为 ContentDialog，宽 480（不超过窗口宽减 48），最大高为客户区高减 80；移除仅改列表，不删磁盘原件。
- 录制／暂停期间设备、校准、路径、格式、品质以及添加／管理校准入口保持可见但禁用，提示「停止后可更改」。管理弹窗内的选择、移除、添加命令也按同一状态守卫，不能绕过冻结。页签本身、主监看模式、增益、PEAK 清除和检查器开关仍可用。避免未来同一录音中途静默改变文件或采集配置。

### 6.3 底栏与录制状态

录制和停止使用同一个右侧槽位，**取消原先从中线飞到右侧的动画**。用户不需要重新寻找关键动作；左侧预留暂停槽，中线时钟有独立占位。Normal 的按钮圆角保留 5；活动按钮相邻内角为 0；间隙 3。无按钮描边、无外围套框。整组总宽 145，右边界稳定，时钟不受按钮宽度影响。

| 录制状态 | 中线 | 右侧 | 计时 | 监看 |
|---|---|---|---|---|
| Ready | 时钟隐藏、占位保留 | 100 × 42 红色录制，圆点 10＋录制 | 隐藏 | 继续 |
| Recording | 240 × 60 状态＋时钟容器 | 左 42 实心暂停；右 100 红色停止图形＋停止 | 累加 | 继续 |
| Paused | 同一时钟 | 左 100 实心三角＋继续；右 42 红色方块 | 冻结 | 继续 |
| Stopped | 时钟隐藏、占位保留 | 原位恢复红色录制 | 隐藏；下一次开始清零 | 继续 |

Record 的圆点 10；Stop 方块 10、圆角 1；Pause 两条 4 × 14 竖杠、间隙 4，置于 18 的图标框；Resume 是 12 × 14 的实心三角，置于相同框。图形使用 XAML 矢量，继承当前文字色，不混用空心与实心。

暂停／继续底色为 TransportButton，文字与图形主白；停止同底，图形与文字 ActionAlert。Hover／Pressed 使用表内 token，不用全按钮 brightness 滤镜连文字也变色。点击指针按下立即有反馈；动画期间允许反向操作。

Native Button 的 Enter／Space、Tab 顺序保留，不新增与路径输入、下拉菜单或 IME 冲突的全局录音快捷键。焦点不因宽度交换丢失；窄停止按钮仍有完整 AutomationName 和 ToolTip。

活动时钟上方用 12 DIP／GainZero 色显示「录制中」或「已暂停」，这是会话状态，不与当前过载灯混用。待机不显示 ready。时钟为 `MM:SS.cc`，满一小时为 `HH:MM:SS.cc`；cc=百分之一秒。用 Stopwatch 单调时钟累计，不能通过 UI Tick 计数。暂定小时位至少两位，小时数超过 99 时自然增长；优先使用 240 容器空间，必要时字号降至 28，不能推动按钮组。

### 6.4 增益

透明底，17 旋钮、1.4 轮廓线、1.5 × 7 指示线，数值 13。0 dB 用 GainZero，非零正负均用 GainActive。范围 −60…+24 dB，0.1 分辨率，是原型候选范围，不称为专业标准统一规定。

- 指针上拖增加、下拖衰减：0.25 dB/DIP；Shift=0.025。捕获指针，离开热区仍继续。
- Esc／PointerCanceled 恢复本次拖动起点值；正常释放或捕获丢失则提交当前值。
- 方向键每次 1 dB，Shift＋方向键每次 0.1；Home 或数字 0 归零；双击归零沿用用户已确认规则。
- 聚焦后 F2 或 Enter 打开原位数值输入，回车提交、Esc 撤销。只接受数值及可选 dB 后缀，有限数，限幅并四舍五入到 0.1，消除负零；无效值保留输入并显示提示。
- 拖动、编辑、键盘、恢复状态都调用同一 `SetGain`，同时更新显示和模拟增益后数据。悬停／聚焦提示说明拖动和精调；只在调整时显示 −60／0／+24 的轻量提示，不加常驻滑杆。

此操作模型更接近 FabFilter 的纵向旋钮。Adobe 文档中的左右拖动＋Shift 加速只作为对照，不混称。

## 7. 三种监看、绘制层次与状态语义

### 7.1 电平与 VU

主读数首先呈现当前 RMS；其下是单位和独立当前过载状态，再下方为历史 PEAK。历史摘要不再抢占当前值前面的阅读顺序。

当前状态在单位行右侧保留 74 × 16 区域：未过载时图标和文字全部隐藏，不显示无说明灰点；当前源峰值或增益后输出峰值达到 0 dBFS 时显示 6 DIP 红灯＋红色「过载」两字，并有小范围红光。隐藏时仍保留槽位，读数不跳动。AutomationName 明确是当前输入／输出过载状态。

历史 PEAK 行只有「PEAK 数值 dBFS＋清除」，没有当前灯。Normal 为 DisplaySecondary，保持值达到 0 dBFS 后为 ActionAlert；重置图标 14，热区 24 × 28，始终灰。当前提示与历史行物理分开，只在过载发生时显露并配文字，避免无说明灰点或灰灯＋红字被误读。

清除将历史值置空 —，下一份数据重新累计，不改变当前灯、输入、增益或计时。当前信号回落时当前提示隐藏，历史过载 PEAK 仍红。

**表盘外观锁定为用户图二对应的既有 HTML 版本，不采用上一张示意图的简化表盘。**完整保留两束贝塞尔扇形灯光、软灯源、底部渐隐、弧面反光、发光刻度、细亮指针和渐变轴心；不使用硬扇形色块、孤立白点、加粗刻度或另造几何近似。原生移植对照 `prototype/recorder.js` 的 `drawVu`，静态预览使用其绘制公式重绘，仍不冒充 WinUI 截图。VU 刻度的 11 DIP 与 VU 标识的 16 DIP 沿用原表盘，其余图表轴字按 12 DIP。

两个 VU 在所选单声道示例中读取同一状态。沿用 HTML 的 −20、−10、−7、−5、−3、0、+3 标记与 −153°…−27° 角度映射，画布 260 × 159，半径 104，底部轴心和暖色扇形光保留。静态表盘／光缓存；每次只绘制动态指针。刻度保持暖色，不把 VU 的 0 当数字满刻度。

本阶段 VU 值是模拟快照独立字段，不能把任意平滑 RMS 宣称为实现了标准 VU 响应。

### 7.2 频谱

绘图区占主监看区全部宽度。左右绘图内边距 46／22，上 12，下 40；实际数据范围 20 Hz…20 kHz（对数），相对电平纵轴 +6…−90 dB。宽 820 时轴刻度延续 20、50、100、200、500、1k、2k、5k、10k、20k；标签不得穿出控件。

绘制顺序：次网格→主网格→曲线下局部渐变→柔光→1.8 DIP 主曲线→轴文字。主／次网格为 ChartGrid／Separator 的低透明度版本，标签在所有渐隐之后绘制。横向最外 5% 渐隐；只对图形和网格渐隐，不吞掉 20 Hz／20 kHz 标签。

金色辉光直接由同一份增益后 RMS 驱动，保留 −34…−30 的模拟视觉映射和二次增强；回落下一数据帧立即收光。不得用历史 PEAK 驱动，不加入冻结或无意义彩虹。此处不是标准响度测量，也不实现真实 FFT。

### 7.3 音高与频率

左 200 的音名／频率／平直音分尺，右列为图表。音分尺宽 200、高 50，中心金标 2 × 24，两端各 27% 渐隐；刻度 −50…+50、步长 5、每 25 长刻度和数字。无「稳定基频」「音分偏差」冗余行。

右图固定 36 半音跨度，初始 C2…C5，四秒历史。图表左／右／上／下内边距 32／8／16／28。当前音高距目标视窗边缘不足 3 半音时，设置新目标，给当前音高留 7 半音余量；整个纵轴和历史曲线共享平滑坐标映射。时间常数 55 ms，约 165 ms 达到 95%；不改变跨度，不拉伸曲线。

历史约 20 Hz 采样，右侧 76% 起渐隐，末端归零；y 轴标签最后绘制，不受渐隐。当前音名、八度、Hz、音分都来自同一 MIDI 模拟状态。无有效音高时为 `—` 和断开的轨迹，不能保持上一音并谎称当前有效。

## 8. 动效规范与输入优先

| 动作 | 时间 | 缓动／规则 |
|---|---:|---|
| 开始／停止 | 100 | 原位图标／前景／底色过渡，不移动按钮 |
| 暂停后宽度交换 | 200 | cubic(0.22,1,0.36,1)，总宽 145 恒定 |
| 检查器展开／收起 | 220 | cubic(0.22,1,0.36,1)，同一路径反向 |
| 主模式切换 | 100 | 仅透明度，不整屏滑动 |
| 状态和时钟进入 | 120 | 同一固定槽位淡入，无延迟等待 |
| Hover／Pressed 颜色 | 80／立即 | 无弹跳、无缩放 |
| 品质条件行显露 | 120 | 轻微透明度；布局立即确定并保持焦点 |

原先 560 ms 飞移被取消，固定目标优先。精确时间是项目自己的选择，不称为 Apple 推荐毫秒值。任何动画均可中断，禁止禁用按钮等待动画结束；迅速录制→暂停→继续→停止时最终状态准确，无遗留图层。

`UISettings.AnimationsEnabled=false`：颜色过渡、宽度、面板和纵轴直接切到终点，时钟无延迟淡入；保留实时数字和必要监看数据更新。不要把减少动态效果误实现为停止整个录音时间或数据来源。

## 9. 可访问性与真实使用边界

- 普通文字以 4.5:1、必要非文字以 3:1 为研究基准；低对比网格和装饰背光不承载唯一信息。
- 所有操作是 Button／ComboBox／TextBox／ContentDialog，保留原生 AutomationPeer；画布只绘图，不承包按钮和字段。
- 数字和图表提供可读当前值及单位；不把 20 Hz 数值设为 LiveRegion。录制状态、过载进入／离开、校准列表操作各通知一次。
- 收起检查器时 Tab 顺序：配置开关→三模式选择器→PEAK 清除（仅电平页）→增益→暂停／继续（活动时）→录制／停止。仅实际可见、可用项进 Tab，模式条内用左右键；不能漏掉画布旁的清除按钮。
- 打开检查器时焦点先到其页签；面板内依次当前页字段／链接→关闭。inline 随后继续到主区模式、PEAK、增益和录制动作，overlay 则在面板内循环。隐藏页和禁用字段不得进 Tab；关闭回到配置开关。
- 全部可见图标有可访问名称；ToolTip 只是补充。无效输入有文字提示，红色不是唯一反馈。
- 窗口关闭即结束本次模拟会话；因没有音频文件，不弹虚假的「保存录音」对话框。真实保存／异常退出策略留给服务接入阶段。

### 10.2 模块与接口边界

- `MainWindow`：TitleBar、窗口尺寸、DPI、inline／overlay 检查器。
- `ShellViewModel`：显示模式、检查器页签、录制阶段、增益、当前快照、历史峰值、文件选项、面板开关与用户操作命令。
- `Controls`：DisplayModeSelector、InspectorPane、TransportBar、GainControl、LevelReadout、VuMeterPair、SpectrumView、PitchView。
- `DesignResources`：上述颜色、文字、间距、圆角和状态模板集中管理；不得每页再定义不同的灰字或字重。
- `MockMonitorSource`：唯一模拟数据源，提供快照；不引用音频采集／DSP／编码程序集。
- `TransportSession`：Stopwatch 计时和 Ready／Recording／Paused／Stopped 转换，与监看数据独立。

最小快照字段为 `RmsDbfs / SourcePeakDbfs / OutputPeakDbfs / VuLeft / VuRight / MidiNote? / FrequencyHz? / Cents? / SpectrumBins`，使用一个不可变快照交给 UI。显示模式切换不创建新数据源。原生内部类型是新项目边界，不伪装成已稳定的正式音频服务协议。

首版使用 INotifyPropertyChanged＋ICommand，不引入额外 MVVM／DI 框架。未来可以替换快照提供者，正式采集线程和文件写入协议到接服务阶段再定。

XAML 承载全部主文字和交互；Win2D CanvasControl 承载 VU、曲线和音分尺。静态背光／网格／文本格式缓存，动态数据最多 30 Hz 重绘，模拟快照约 20 Hz，时钟约 30 Hz；不在每次 Draw 创建整套画刷与 blur 资源。最小化暂停绘制，恢复后用单调时间恢复正确计时；后台不以丢掉 UI Tick 计数导致计时变慢。

原生 FolderPicker／FileOpenPicker 使用 `Microsoft.Windows.Storage.Pickers`，关联当前 AppWindow；支持取消和异常处理。只选路径／元数据，不启动读文件内容、校准和编码服务。配置仅保留本次会话，不把 UI 样机变成另一个配置持久化项目。

## 11. 模拟场景与验收明细

开发专用入口 F12 打开场景选择，普通主界面不放常驻调试控件。场景只改变 ViewModel／MockMonitorSource，不伪造音频成功提示。

| 场景 | 必须可观察的结果 |
|---|---|
| 正常待机 | −32.0 左右 RMS、普通灰 PEAK、单位行无过载提示、右侧红录制 |
| 增益后输出过载 | 单位行当前灯＋过载文字红；下方历史输出 PEAK 字红；重置图标灰 |
| 输入过载、负增益后输出未过载 | 当前灯仍红并提示输入过载；历史 PEAK 仅按输出峰值判断，不因输入灯红而被强制染红 |
| 历史过载、当前恢复 | 当前提示隐藏而历史字红，能分辨当前与过去 |
| 清除峰值 | 显示 —，下一帧重新累计；当前灯由当前输入决定 |
| 录制→暂停→继续→停止 | 状态表、宽度、时钟与动作名称一致；录制／停止原位，监看不中断 |
| 快速连续点击 | 动画可中断，无幽灵按钮／错位／焦点丢失 |
| 00:59.99／59:59.99／01:00:00.00 | 分／小时位正确、计时居中、按钮不跳动 |
| 增益 −0.1→0→+0.1 | 数字蓝→灰→蓝，无负零；拖动／键盘／输入一致 |
| 设备名称与顶栏对齐 | 菜单图形和设备名字形中心线一致；切换模拟输入后标题同步，未选／断开有明确文案 |
| 路径行圆角 | 输入框、浏览按钮各自四角为 3 DIP，包括相邻两边，无共享底面 |
| 中文及超长文件名／路径 | 可编辑、完整提示，浏览按钮和箭头不被挤走 |
| WAV→MP3→FLAC→WAV | 品质条件行正确，各自记忆选择；不声称已经编码 |
| 高音／低音越界 | 36 半音跨度不变，轴字和曲线同步平移 |
| 无有效音高 | 音名／Hz 为 —，轨迹断开 |
| INPUT／FILE 两页 | 模式彼此独立，各页恢复值、焦点和滚动；默认高度能看到完整 FILE 设置 |
| 打开检查器时录制 | 中线和组内位置稳定，不重置计时；配置控件禁用 |
| 空间不足打开检查器 | overlay＋遮罩＋焦点约束，无小 VU 或重复触发底层按钮 |
| 减少动态效果 | 无过渡，操作结果、数据和时钟仍正确 |
| DPI／文字缩放 | 数字无裁切、字体不被 Viewbox 压扁、窗口可操作 |

默认音高演示为 18 秒循环：B2 稳态→G5→C1→B2，专门穿越初始 C2…C5 范围；频率／音名／音分来自同一状态。真实声音准确性不在样机验收范围。

阶段二按现有约定**不运行自动测试或浏览器 QA**。必须完成原生编译和启动，给用户可运行窗体；上表是待人工检查清单，不在本轮标成已通过。字体 A／B 要以同一 DPI、同一窗口尺寸、同一数据场景截图比较。
