# URAW Recorder v1.0.7

本次更新调整了首次使用时的默认设置，完善了峰值读数的重置行为，并修复了关闭应用内弹窗时背景偶发闪烁的问题。

## 更新内容

- 首次使用默认采用共享模式。已有用户继续沿用此前保存的录制模式。
- 首次切换至独占模式时显示说明，提醒麦克风占用、Windows 软件增益失效及手动调整增益的影响。
- 默认录音保存位置改为桌面下的 `URAW Recorder Recordings` 文件夹。文件夹在开始保存录音时创建，已有自定义保存路径继续保留。
- 开始或停止录制、开始或停止侦听时，自动重置 PEAK 历史峰值。暂停录制时继续保留峰值。
- 统一菜单按钮与录制、侦听选项的悬停色调。
- 移除最大化按钮和顶部区域的浅色遮罩。
- 删除与正文重复的弹窗标题。
- 修复关闭应用内弹窗时背景偶发回暗、闪烁的问题，使弹窗与背景同步淡出。

## 下载与运行

下载 `URAW Recorder v1.0.7.exe`，双击运行。程序面向 Windows x64，内置 .NET、WinUI 和音频编码器，无需另行安装 .NET 或 FFmpeg。首次启动会提取运行文件。

本版本继续支持 WAV、FLAC 和 MP3 录制。

## 附件说明

- `URAW Recorder v1.0.7.exe` 为可直接运行的单文件程序。
- `URAW-Recorder-v1.0.7-FFmpeg-source.zip` 提供所附编码器的源码与构建材料，普通使用无需下载。
- `SHA256SUMS-v1.0.7.txt` 用于校验程序文件。
