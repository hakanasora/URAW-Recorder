# 麦克风校准：实现与验收

本轮为真实频响补偿，不是仪表读数偏移。保持原有 WinUI 布局、材质、VU 外观、采集模式与浮点 WAV / RF64。

## 使用

1. 待机打开「输入 → 校准 → 添加校准」，选择 `.txt` 或 `.cal`。文件先解析、验证，再复制到应用校准库；同内容不重复导入。
2. 在校准下拉框选择当前麦克风的文件。对话框显示启用状态、原始频段、作用声道数、实际处理延迟和拟合误差；「不使用校准」是真正直通。
3. 每个 Windows 端点 ID 独立记忆选择。相似名称和系统默认设备不会触发曲线迁移。新设备默认不校准；同一设备全部声道共用曲线，每路滤波历史独立。
4. 录制和暂停期间不能导入、切换或移除校准。待机切换在处理线程的样本边界生效，清空旧分析窗、轨迹和 PEAK。
5. 已添加的校准可管理、悬停移除、添加；移除仅删除应用副本和绑定，绝不删除用户原文件。原文件移动不影响使用。

库位置：`%LOCALAPPDATA%/PortableRecorder/Calibrations/`。文件以 SHA-256 命名，`calibration-library.json` 原子替换保存索引和端点绑定，独立于录制模式偏好。副本缺失、指纹不符和索引损坏会明确停用。记忆的校准不可用时允许明确提示下的未校准监看，但阻止悄悄开始未校准录音，必须修复选择或明确关闭校准。

文件名、序列号和方向备注只用于说明；用户负责选对实际设备及其朝向对应的文件，不新增朝向选项。

## 信号与测量

```text
WASAPI / PCM 解码 → 原始入口满刻度检测 → 频响 FIR → 软件增益
    ├→ 同一份样本：300 ms RMS、历史 PEAK、VU、频谱、音高
    └→ 按源帧区间选取 → float32 WAV / RF64
```

文件记录麦克风响应，应用补偿为其相反数。在对数频率上对响应 dB 线性插值，再转为线性幅度。曲线频段之外目标为 0 dB；有限 FIR 在频段边缘存在过渡，不无限延伸曲线。无校准、全零响应都不增加滤波延迟。

NWaves 0.9.6 的 `DesignFilter.Fir` 设计线性相位 FIR，`OlaBlockConvolver64` 处理每个声道；FFT 和快速卷积均复用成熟库。准备、验证在后台完成，失败保留当前配置。每次捕获会话、采样率变化、曲线切换、间断恢复都重新建立必要的滤波状态。

| 实际采样率 | 卷积 FFT | FIR 系数 | OLA 块长 | 总额外延迟 |
|---|---:|---:|---:|---:|
| 44.1 kHz | 16,384 | 14,337 | 2,048 | 9,215 帧 / 208.957 ms |
| 48 kHz | 16,384 | 14,337 | 2,048 | 9,215 帧 / 191.979 ms |
| 96 kHz | 32,768 | 28,673 | 4,096 | 18,431 帧 / 191.990 ms |
| 192 kHz | 65,536 | 57,345 | 8,192 | 36,863 帧 / 191.995 ms |

一般参数：`N=nextpow2(Fs×0.34)`，`M=7N/8+1`，设计 FFT `4N`，Hamming 窗。总额外延迟为 `(N−M)+(M−1)/2`，包括 OLA 块等待与 FIR 群延迟。它不包含设备缓冲、RMS 统计窗等本来存在的时间。

设计验证使用独立的 NAudio FFT 核对实际加窗后的系数，在 20 Hz～20 kHz 与文件频段、Nyquist 的交集检查 2,049 个对数频点、全部文件频点及其对数中点。超过 0.1 dB 拒绝启用，不悄悄降低精度或截断曲线；过尖、过窄、强突变的其他文件可能不满足当前 FIR 精度要求。

软件增益按源帧对齐，变化不会错误作用于此前已进入滤波器的帧。不限制 ±1，不归一化；原始入口满刻度标志保留，后续衰减不能掩盖它。VU 的 −18 dBFS 峰值参考及 RMS / PEAK 定义不变。

## 不应用的能力

- 非零相位文件可以导入和查看拒绝原因，但不能启用。线性相位滤波不是恢复了麦克风的原始相位。
- `Sens Factor` 和其他灵敏度头部保留，不作为音频增益。未验证设备类型与输入增益关系前不输出 SPL。当前两份 UMIK 文件仅应用频响，明确显示绝对声压未启用的原因。
- 音高算法用校准后波形；A4=440 Hz、采样时钟和音高基准未被幅频文件标定。
- 不识别文件中不存在的校准能力，不暗加限幅、自动增益、降噪或重采样。

## 解析和失败规则

UTF-8 / ASCII / 带 BOM 的 UTF-16 LE 或 BE；固定小数点，不依赖区域设置；空格、Tab、明确逗号、科学计数、注释、常见带引号头部。2 MiB、100,000 点、至少两点；频率正数、有限、严格递增；幅值有限且在支持范围内。重复、倒序、损坏数字、二进制字符、数据段中的未知内容、网页错误和冲突头部按行报错。三列文件要求相位全部为零。需要超过 +24 dB 提升、无音频频段交集、不支持的采样率或拟合不达标不能启用。

## 录音边界与收尾

处理结果带源帧起点；快照携带校准版本和延迟。录制、暂停、继续、停止在串行命令边界记录原始源帧区间，写盘选择的是该区间对应的校准后样本。滤波延迟不会变成预录，不插入暂停静音，也不会把暂停区间的延迟输出接进文件。

正常暂停和停止异步等待相应源帧的输出送入写盘队列，处理线程继续接收真实采集包，不阻塞等待未来输入。停止后排空写盘队列、完成头，再释放独占。采集停止、关闭窗口、断流采用仅针对已接受样本的数学收尾，缺失样本不补造成真实录音。数学收尾后的处理器不能继续沿用其推进后的时钟；共享监看重新建立处理器。等待真实尾部超过 3 秒会报不完整，而不是无限挂住。

队列溢出、非有限处理结果和磁盘失败明确停止。断流后的历史窗不与新段拼接；录制中发生真实间断仍按已有策略停止并标记不完整。

每个 WAV 旁保存 `<文件名>.wav.calibration.json`，含设备 / 格式、原始曲线、指纹、头部、实际 FIR / FFT / 延迟参数、能力声明、帧数和完成状态。摘要以临时文件写入并原子改名，绝不覆盖同名文件。摘要失败与 WAV 失败分开提示；丢弃仅删除本次 WAV 和本次实际创建的摘要。
