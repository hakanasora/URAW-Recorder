## 为什么 +3 VU 不等于数字削波

本产品已确认的参考为：1 kHz、峰值 −18 dBFS 的正弦 = 0 VU；峰值 −15 dBFS 的同类稳态正弦 = +3 VU，仍离 0 dBFS 有 15 dB。VU 是带时间响应的平均整流表头，PEAK 是逐样本峰值，两者不同。语音的峰均比和声道能量又会让数字大读数与指针不相同。**不能为了让指针与 PEAK 同步而改成峰值表。**

保留检测器和参考电平，在仪表区域提示明确标出“+3 VU 不代表数字削波；数字超限看 PEAK ≥ 0 dBFS”。参考 [VUMT 说明](https://klanghelm.com/docs/VUMTdeluxe-manual.pdf) 的校准关系，具体计算依本产品定义。

## 本轮修改

1. **显示**：设备名不再把渐变直接刷到混合字体文字上。整行以统一文本图层绘制、仅末尾 24 DIP 做 AlphaMask 渐隐，避免中文字 / 拉丁字混排时出现中间空洞和尾部再次出现。保留完整辅助名称、真实声道提示和录制时的擦除宽度动画。
2. **模式下拉**：按用户后续纠正，已恢复上一版原生 ComboBox 外观及弹出方式，撤回 DropDownButton / MenuFlyout 改动；保留独占 / 不独占选择的跨设备、跨启动记忆。
3. **丢弃**：仅暂停时出现白色垃圾桶，位于继续左边；外侧 5 DIP 圆角、相邻内侧直角、3 DIP 间隙，继续为中段，停止仍为右段。提示和辅助名称为“丢弃”。只移除当前生成的文件；非暂停不执行。关闭、排队收尾、删除失败都会走错误处理，绝不触碰此前文件。
4. **设备**：复用 NAudio 3.3.0 原生 MMDeviceNotificationClient 事件，不轮询音频、不在 COM 通知线程中枚举或关闭采集。300 ms 合并后刷新输入列表。待机新插入输入自动选择；录制中若原设备还在，列表更新但不换源；原设备拔出，则结束当前录音并恢复剩余设备的共享监看，新插入时可自动恢复。不会把两支设备拼进同一文件。默认设备标记变化不强行抢走有效输入。
5. **模式记忆**：`%LOCALAPPDATA%/PortableRecorder/preferences.json` 原子写入用户最后选择；设备切换、刷新和重启均不重置。文件坏损时回退首次默认独占；RAW 普通共享许可仍只在内存按当前设备生效。
6. **刷新与成本**：绘制从状态更新定时器分离，跟随合成回调、上限 120 Hz，减少动态效果模式上限 60 Hz；高于 120 Hz 的屏幕用累计截止时间限频，避免 144 Hz 简单隔帧变成 72 Hz。指针只对相邻测量结果作无过冲插值，频谱作 20 ms 像素过渡，音高视窗按显示时间滚动。FFT / 音高检测和写盘不为动画提频；缓存指针辉光、网格和表盘，最小化不绘图。实际 Draw 次数写日志，未冒称已实测达到 120 fps。较高绘制频率仍会增加一部分 CPU / GPU 成本，具体占用待实际屏幕检查。

## 后续：跟随当前屏幕刷新率与音分尺

撤回固定 120 Hz（减少动态效果时 60 Hz）上限：用 MonitorFromWindow / GetMonitorInfo 定位窗体所在屏幕，QueryDisplayConfig 的当前活动路径读取有理数刷新率，保留 59.94 等精度，不取显示器标称最大值；必要时退到 EnumDisplaySettingsEx 的 ENUM_CURRENT_SETTINGS，读取失败则直接跟随合成回调，不虚构刷新率。拓扑查询每秒一次，在后台线程执行，跨屏、系统更改显示模式后自动更新。这里读取的是 Windows 当前显示模式，不声称是 VRR 每一帧瞬时扫描频率。实际呈现仍受 XAML / DWM 和机器负载限制。

音分尺改为每个绘制帧推进的 35 ms 指数平滑，系数按真实经过时间计算，所以 60 / 160 / 240 Hz 的运动速度一致。只平滑刻度位置，不改变检测的音高 / 音名 / Hz / 音分结果或录音。切换音名时重置，不从 +49 音分错误地横扫至 −49；无效音高和新会话清空旧运动，减少动态效果时直接显示测量目标。

171 项后台断言通过；只读调用系统 API 在本机默认屏读取到 DISPLAY6 / 160.000 Hz。此结果证明查询路径能工作，不等于已测得应用实际呈现 160 fps。未打开窗体或麦克风；本轮发布及实窗流畅度仍按各自记录区分。

API 依据：[QueryDisplayConfig](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-querydisplayconfig)、[当前显示模式](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumdisplaysettingsexw)。
