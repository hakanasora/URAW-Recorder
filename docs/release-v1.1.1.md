# URAW Recorder v1.1.1

独占模式现在从待机开始独占麦克风，停止录制后仍保持独占。可以先看着电平表调好输入增益，再开始录音。录制前后沿用同一采集方式，避免停止时切回共享导致电平突变。

- 选择的独占输入格式会立即用于待机监看，也用于随后的录制。
- 独占采集打开失败时，程序保留当前选择并提示错误。刷新输入设备即可重试。
- 首次独占提示已缩短，说明待机时的麦克风占用，以及电平偏低时如何调节增益。

## 下载与运行

下载 `URAW.Recorder.v1.1.1.exe`，在 Windows x64 上双击运行。程序内置 .NET、WinUI 和音频编码器，支持 WAV、FLAC 和 MP3。

使用 `SHA256SUMS-v1.1.1.txt` 校验附件。`URAW-Recorder-v1.1.1-FFmpeg-source.zip` 包含随附编码器的源码、构建脚本和许可文件。
