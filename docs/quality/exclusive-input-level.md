# 共享／独占输入电平差异（2026-10-30）

用户视频 `VID_20261030_031859.mp4` 约第六秒点击录制后，UMIK-1 的读数从约 −24 dBFS 降至 −55 dBFS。日志证实同一设备从共享 RAW 48 kHz float32 双声道切换到独占 RAW 48 kHz PCM24 双声道。

只读查询：Windows 端点音量为 +30 dB，HardwareSupport 仅包含 Mute，不包含 Volume。微软说明，软件端点音量作用于共享流，独占流绕过软件音量；硬件音量则可能作用于两者。RAW 不保证绕过共享音量。

用户授权约二十秒后台占用 UMIK-1，按共享／独占／共享／独占分别采集约四秒。不播放声音、不改变系统音量；只在 artifacts 中保存统计，没有保存音频。每轮忽略启动第一秒，不应用校准和软件增益。RMS 分别为 −32.02、−63.21、−33.95、−63.01 dBFS。环境声并非相同信号，不能据此计算精密增益误差；约 29–31 dB 的差异与端点 +30 dB 的机制相符。采集正常结束并释放麦克风。统计在 `artifacts/exclusive-level/comparison.json`。

静态审查未发现 PCM24 比例错误；既有 PCM 正负满刻度、24-in-32、测量准确性检查保持通过。没有为“看起来一致”而放大独占样本，也不修改系统设置。

界面修正：输入菜单说明当前采集模式及系统输入增益，并区分共享软件增益、独占绕过、硬件控制及未知信息。读数为打开流时快照，不是实时音量订阅；提示更改系统音量后刷新。诊断日志保存端点增益及硬件支持情况，查询失败保持未知。不会将这个数值加到处理样本或录音文件上。

针对性验证：dsp 与 regression-ui 共 205 项断言通过，发布构建通过。未进行新的实窗视觉验收。前台操作虽获许可，本次无需使用。
