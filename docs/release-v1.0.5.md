# URAW Recorder v1.0.5

本次更新缩小了单文件下载体积，并改进通知内容和界面资源管理。

## 下载与运行

下载 `URAW Recorder v1.0.5.exe`，双击运行。程序面向 Windows x64，已在 Windows 11 上验证，内置 .NET、WinUI 和音频编码器，无需另装 .NET 或 FFmpeg。

首次启动会自动提取运行文件，请保留足够磁盘空间。已有用户的设置和校准文件继续保留。

## 更新内容

- 单文件 EXE 约 72 MiB，相比 v1.0.3 的约 357 MiB 缩小约 80%。精简 FFmpeg 的无关功能，移除未使用的 AI/ML 运行依赖，并启用单文件压缩。保留 WAV、FLAC 和 MP3 录制能力。
- 通知弹窗使用具体提示作为标题，合并重复及同义的校准提示，保留不同的错误原因和处理建议。
- 简化文件格式说明。正常保存成功后，仍可点击右上角提示打开保存目录。
- 修复自定义 DPI 下可能反复调整绘制缓冲区的问题，补齐侦听模式的最小化更新节流。
- 改进分段动画的停止和资源释放，响应系统关闭动画的设置，避免空通知获得隐藏键盘焦点。
- 补充文字绘制控件释放后的保护，以及增益控件的无障碍数值变化通知。

## 验证范围

已检查 WAV、FLAC、MP3 实际短录音与解码，并验证菜单、弹窗、显示模式切换和关闭窗口。本次发行还运行了自动音频与界面模型检查。

不同声卡、驱动、缩放比例和显卡环境仍可能有差异。多显卡切换、真实显卡设备丢失和长期资源稳定性尚未完整覆盖。

## 附件说明

- `URAW Recorder v1.0.5.exe` 是直接运行的程序。
- `URAW-Recorder-v1.0.5-FFmpeg-source.zip` 提供所附 FFmpeg/LAME 的对应源码、构建脚本和许可材料。普通使用不需要下载它。
- `SHA256SUMS-v1.0.5.txt` 用于校验下载文件。
