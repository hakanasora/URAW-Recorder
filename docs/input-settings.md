# 输入设置与校准菜单调整（2026-10-27）

本轮按已确认大纲实现，保留固定窗体、主界面材质、仪表和原来的抽屉动画。UI 源码核对与编译不能代替实际窗体观察。

## 侧栏结构

```text
设置图标    录制模式
[ 独占 / 共享                          v ]

麦克风图标  输入设备                  刷新
[ 当前输入设备                         v ]
输入格式（二级灰）
[ 实际共享格式 / 独占录制格式设置        v ]  ← 共享时置灰
当录制模式为共享时，该选项不可用            ← 仅共享时显示，灰色小字

校准图标    校准                      管理校准
[ 启用 / 禁用                          v ]
[ 选择校准文件                          v ]  ← 仅启用时显示
```

“不独占”统一为“共享”，现有用户录制模式偏好仍按原枚举读写，不重置。删除原来的灰色格式文字区，实际监看模式、RAW 和格式说明放入输入格式控件提示；校准延迟、声道数、频段及未启用能力放入校准标题 / 开关的提示。未生效校准有可见状态提示，不依靠悬停才知道录制被阻止。

侧栏内容区 384 DIP，顶栏 48 DIP，内容区左右内边距仍 24 DIP。三个一级模块按 **录制模式 → 输入设备 → 校准** 排列，模块间 16 DIP，设备到输入格式子组 8 DIP，标签到字段 4 DIP，形成 16 → 8 → 4 的层级节奏。控件仍高 36 DIP、原字体和配色；常用状态（共享或独占 + 校准禁用）完整落在 312 DIP 视口内。页签与关闭按钮按内容区的 24 DIP 左右边缘对齐，页签下方有 1 DIP 分隔线；输入页滚动条位于右侧 16 DIP 内容留白内、距抽屉右缘 8 DIP，不覆盖控件。启用校准文件行后内容超过视口，仅在输入页内部滚动，并自动把新出现的文件行带入视野；不改变主窗尺寸、抽屉宽度或主界面。刷新位于设备标题右侧，“管理校准”位于校准标题右侧；录制模式与校准均为标题在上、下拉框独占下一行。条件行展开使用 WinUI 原生主题过渡，遵从减少动画设置；没有重新引入 ConnectedAnimation 快照。

## 输入格式的真实含义

- 共享模式只读，显示正在运行的共享流格式。无有效流时可显示最近查询的系统格式，但提示明确说明它不代表正在采集。不写系统设备设置，不私加重采样。
- 独占模式提供“自动（设备推荐）”和当前设备经 WASAPI `IsFormatSupported` 确认的候选组合。候选包括当前设备格式及现有兼容策略的采样率 / PCM / float 组合，保留原生声道数；不是声称穷举了驱动可能支持的全部格式。
- 能力查询在后台创建只读客户端，不调用 Initialize / Start，不占用独占流。RAW 是否实际可用仍在真正打开录制流时检查，格式查询不冒充 RAW 初始化验证。
- 独占格式按端点 ID 写入单独的 `input-formats.json`；切换共享不覆盖记忆。默认自动。选定格式只在独占录制时使用，待机 / 停止仍共享。提示同时列出“独占录制设置”和“当前实际采集”，避免把 96 kHz 目标冒充成 48 kHz 待机监看。
- 显式选择开流失败时不尝试另一个独占格式、不降级共享录制；恢复共享监看并报告。旧选择不再支持时显示“所选格式已不可用”，用户可明确选自动或其他组合。
- 准备 / 录制 / 暂停 / 收尾期间配置锁定，后端也拒绝更改。

### 共享模式下的输入格式

共享模式下输入格式字段保持 `IsEnabled=false`，使用深色禁用底（Inspector 的 `Grid` 色）和灰字，标题降为 `Muted` 二级灰，避免看起来仍可编辑；字段下方显示 11 DIP、`Muted` 色的单行提示“当录制模式为共享时，该选项不可用”，独占模式隐藏。提示和置灰只改变视觉呈现，禁用规则仍由原有 `SyncInputFormat` 控制，没有改动音频引擎、格式查询或偏好持久化。

## 校准开关与文件分离

校准区直接位于侧栏，取消中间校准设置弹窗。启用下拉只有“启用 / 禁用”，文件下拉只有真实文件，不再列“不使用校准”。禁用隐藏文件行，信号真正直通，同时记住此前文件。重新启用可恢复有效文件；没有文件则显示“请选择校准文件”，没有库文件则显示“请先添加校准文件”。启用但未配置或文件不可用时仍能明确提示下监看，不能悄悄录制未校准音频。

校准索引升级为版本 2：Activation 和 Devices 分别保存启用状态与记住的文件。版本 1 的既有文件绑定在读取时迁移为启用，不清除旧配置；用户变更时才原子保存新索引。录制模式偏好与输入格式偏好互不覆盖。

删除当前文件会停用引用它的配置，不自动选择另一份。添加只负责加入校准库，不启用、不代替选择。失败的文件切换保留旧有效配置。解析、FIR、源帧边界、后台指纹校验、录音摘要及浮点保存规则沿用上一阶段。

## 管理校准窗口

“管理校准”是系统强调色链接，位于校准标题右侧，直接打开“已添加的校准”，底部仍为“添加校准 / 关闭”。

- 使用原生 ListView / ListViewItem，SelectionMode=None；悬停底色为中性灰，保留原生焦点反馈。管理窗口不承担应用所选文件的职责。
- 右侧“移除”固定保留 56 DIP 位置，鼠标悬停、键盘聚焦时显示；隐藏时不响应鼠标。原生 Button 的深灰填充、细描边、4 DIP 圆角、28 DIP 高度及悬停 / 按下状态，不再使用透明文字按钮。
- 文件名悬停只显示应用当前使用副本的完整路径。路径解析只拼接受控库路径，不读取、散列或解析文件；原来已有的 SHA-256 文字展示已移除。导入 / 载入时的去重与完整性校验保留。
- 移除仅影响应用副本；录制与暂停时不能修改库。管理窗口内部的文件列表继续允许独立滚动，不是主窗体滚动。
