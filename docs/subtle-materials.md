# 灰黑基调的轻量 Mica 材质

日期：2026-10-25。

## 当前参数微调

当前：Display/标题栏覆盖调回 115/255（约 45.1%），底栏维持 13/255（约 5.1%）。以下试版百分比为历史记录。

最新试版：Display/标题栏覆盖 102/255（40%），底栏覆盖 13/255（约 5.1%，最接近 5% 的 8 位 alpha）。下方 50% 及约 8% 参数均为历史记录。

最新：Display/标题栏覆盖进一步降至 128/255（约 50.2%，即 8 位 alpha 最接近的 50%）；底栏维持 20/255，其他材质及交互保持。以下 60% 参数为上一轮记录。

底栏附加深色覆盖由 0 调为 20/255（约 7.8%），轻微收敛通透感；Display/标题栏覆盖由 176 调为 153/255（60%），稍微增强材质显露。Display 仍显著比底栏更不透明。普通 Mica、选择器半透明填充及无人工渐变的实现保持。以下段落的旧参数为历史记录，以本节为准。

## 最新微调：原生底栏与半透明选择器

继续使用普通 MicaBackdrop（Base），不是 Mica Alt；两者均是壁纸染色的不透明系统材质，Alt 主要增强染色，不能理解为更高的真实透光率。以用户提供的系统录音机底栏为视觉方向，底栏附加覆盖由 32/255 降为 0，完整显露原生 Mica；Display/标题栏覆盖由 112/255 提高为 176/255（约 69%），形成更稳、更不透明的仪表表面。系统不支持时仍使用原纯色。

主选择器底框由不透明 #0A0A0A 改为 alpha 102/255（40%）的同色填充；两个选择器共用的选中底面改为 alpha 36/255（约 14%）白色填充。仅背景与底面参与混合，文字、焦点及 180 ms 平移动画保持，不对整个控件设置透明度。

未重新引入 Acrylic 或人工灰阶渐变。必要发布编译和 Git 差异核对通过；启动与实际材质视觉分开验收，不声称与系统录音机逐像素一致。

下方覆盖参数为历史记录，以本节为准。

## 当前版本：撤回 Acrylic，统一普通云母

按用户反馈，已通过 Git revert 撤回 623636d 的局部 Desktop Acrylic 方案，删除其控制器及背景承载元素。当前整个窗口共用普通 MicaBackdrop（Base），与 Windows 设置背景的材质方向一致，不再使用 Mica Alt。

底栏覆盖 #0E0E0E、alpha 32/255（覆盖约 12.5%），让原生云母明显呈现；Display 和标题栏覆盖 #1B1B1B、alpha 112/255（覆盖约 43.9%），比底栏更不透明。这里是附加覆盖比例，不是系统云母本身的透明度。

移除所有人为叠加在显示面板上的灰阶顶光渐变及顶部高光线，避免只有少量灰阶台阶的渐变造成断层；显示面板只保留均匀填充，空间变化交给系统云母。系统材质本身的最终渐变表现仍需实窗观察。

原有布局、设备名字形渐隐、VU 与模拟交互保持。不支持 Mica 时使用原纯色；透明效果策略由系统处理。必要发布编译、启动日志与 Git 差异核对，不运行完整测试或浏览器校验。

## 先前记录：增强材质试版（已替代）

用户反馈首版几乎无法察觉。当前改用 MicaBackdrop BaseAlt，允许更明显的壁纸染色；显示区中性覆盖 alpha 160/255（底材透出约 37.3%），控制区覆盖 alpha 144/255（底材透出约 43.5%）。基准色仍是 #1B1B1B / #0E0E0E，实际像素由系统材质与覆盖层共同决定。

显示面板顶光白色 alpha 8/255，向下在 80% 高度处淡至透明；顶部及底栏交界细线白色 alpha 14/255。保持原布局、文字、按钮与绘图；不支持材质时仍使用原不透明纯色。参数集中在 MaterialSurface，便于继续调节强度。

必要发布编译和差异核对通过；启动及材质视觉效果分别核对，不以编译成功代替视觉验收。

## 首版记录（已被上方参数替代）

- 窗口采用系统 MicaBackdrop（Base），不使用 Mica Alt 或 Acrylic。根背景透明，同一原生背景供各区域共享，不新增窗口或模糊循环。
- Display 以 #1B1B1B 为基准，覆盖 alpha 238/255 的中性面层，约 6.7% 底材透出。头部与监看区形成连续表面；顶部 1 DIP 轮廓为白色 alpha 5/255，顶光为白色 alpha 3/255，向下淡至透明。布局与圆角不变。
- 控制区以 #0E0E0E 为基准，覆盖 alpha 242/255 的近黑面层，约 5.1% 底材透出；交界线为白色 alpha 10/255。标题栏沿用显示区面层，标题按钮背景透明。
- 覆盖比例用于抑制壁纸染色，不保证最终像素等于基准 HEX。系统处理激活状态及透明效果策略；不支持 Mica 时使用原有不透明纯色，并省去顶光。
- 设备名通过原生 TextBlock 的透明渐变前景淡出，末尾 24 DIP 按实际文字和视口宽度定位，移除固定底色遮盖。保留录制擦除、完整名称提示及麦克风图标。
- 三种显示共享材质，文字、VU、曲线、布局及模拟交互不变。

必要 Release 编译、发布及 Git 差异检查通过；启动日志记录 Mica 支持状态。材质强度、壁纸切换及非激活状态尚未实窗视觉复核，不运行自动测试或浏览器校验。

实际发布 EXE 已启动，日志记录 Mica=True、Loaded 完成及 820 × 236 DIP 监看首帧，进程正常响应；这不替代材质视觉验收。
