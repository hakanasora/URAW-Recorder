# 频谱坐标试版

日期：2026-10-25。仍是模拟 UI，不新增音频服务。

## 横轴

保留 20 Hz 到 20 kHz 的对数频率映射，主标签按参考图调整为 20、100、500、1k、3k、10k、20k。坐标为 log10(f/20)/3，不将七个标签等距排列。100/1k/10k 相隔相同距离；十倍频程内部用 1～9 倍频点生成次网格，不重复绘制主网格。

## 纵轴

采用显式标注的“dB · 非线性”分段显示映射；自上而下 0、−6、−12、−24、−48、−96 dB，主刻度各相隔绘图区高度的五分之一。每个区间内线性插值，区间边界连续，次网格取该区间 dB 中点。−48 到 −96 的 48 dB 范围压缩在最底部 20% 高度。

dB 本身是对数单位，本次额外调整的是 dB 读数到屏幕高度的关系；不能把这条曲线的屏幕斜率当作等距 dB 轴上的频响斜率。高于 0 的值钳在顶端、低于 −96（含负无穷）及 NaN 钳在底端，数据本身不修改；PEAK 和过载判定不变。保留低电平信息，不把数字电平直接解释为真实响度。

## 数据边界与服务衔接

当前 211 个模拟样点按 20 Hz～20 kHz 的对数频率均匀排列，渲染通过明确的模拟频率映射得到横坐标；这与线性 FFT bin 的编号规则不同。未来接入服务必须按真实频率（及采样率、FFT 长度）投影，不能直接把线性 FFT 数组按等间距画进对数轴。本轮不改变 MonitorSnapshot 或公共服务接口。

参考截图的 SPL 刻度不用于当前 UI；真实 SPL 需要相应测量链路与校准，当前校准文件仍只管理名称和路径。

## 最小核对

核对端点 20/20k 对应左右边缘、1k 和 3k 的真实对数位置，以及六个 dB 主刻度对应 0/20/40/60/80/100% 高度；标签、网格与曲线共用 SpectrumScale。必要 Release 发布编译及 Git 差异检查通过，启动检查单独记录；不运行完整自动测试或浏览器校验，尚未实窗复核标签排版。

依据：[频谱分析器的对数频率坐标](https://www.mathworks.com/help/dsp/ref/spectrumanalyzer.html)。非均匀 dB 分段是本产品本轮的显示试验，不声称是标准测量坐标。
