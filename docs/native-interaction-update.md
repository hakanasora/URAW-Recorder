# 固定窗体与原生交互更新

日期：2026-10-24。此文优先于研究快照中关于自由缩放、覆盖侧栏和窗口滚动的旧方案。

## 窗体与左侧菜单

- 收起时客户区为 **820 × 416 DIP**；打开菜单为 **1084 × 416 DIP**。标题栏 32，主界面 820 × 384。
- 禁止拖拽边框调整大小和最大化；标题栏仍用于移动窗口位置。
- 主界面宽度始终 820；菜单只在左边增加 264。收起只撤掉该区域，主界面不参与重新缩放。
- 使用原生 WinUI `SplitView` 的 Inline 左侧面板及其主题动画。关闭动画结束后才撤回外层窗口面积。
- `FixedWindowFrame` 以两个常量尺寸计算窗口，完全移除对临时 `ActualWidth` / `ActualHeight` 的回写。状态重复到达同一端点时不再改变窗口；快速反向操作的过期回调不会撤掉新打开的菜单。
- 窗口靠屏幕左缘时，展开后的整窗向可用工作区内约束，避免菜单掉到屏幕外。DPI 改变仍重新换算相同 DIP 尺寸。
- 主界面与设置页都没有 ScrollViewer，不接受整页滚动。下拉列表、校准管理列表和系统文件选择器仍保留各自的正常操作。
- 菜单页签改为“输入／文件”。顶栏以独立 Grid 列分配页签与 32 × 32 关闭热区，关闭按钮内边距为 0；菜单按钮也移除挤压图标的内边距。

## 动效

| 场景 | 原生实现 | 时长 |
|---|---|---|
| 菜单伸出／收回 | SplitView 原生主题动画 | 遵循控件主题 |
| 监看／菜单选择条 | ConnectedAnimation + DirectConnectedAnimationConfiguration，仅移动选中底面 | 180 ms |
| 监看内容切换 | 原生 XAML Opacity 动画 | 120 ms |
| 录制／停止与暂停组合 | 复用同一个主按钮；原生 Width / Spacing 伸缩、底色过渡、内容淡换 | 240 / 160 / 160 ms |
| 暂停后继续／停止交换宽度 | 固定右边界，组内 42 / 100 互换 | 240 ms |
| 时钟出现／收起 | 固定中央槽位淡入／淡出 | 180 / 120 ms |
| “录制中／暂停中”切换 | 旧文字淡出后替换，新文字淡入 | 75 + 100 ms |
| 暂停状态 | SineEase 透明度 1 ↔ 0.45，平滑往复 | 每半程 1500 ms |

开始录制时暂停区域从零宽伸出，录制主按钮原位过渡成停止；停止后反向收回。时钟的出现不挤动其他控件。连续操作会中断旧动画并按最新状态落位；暂停呼吸在继续或停止时取消。系统关闭动画时直接显示终态，计时与监看数据照常刷新。

## 核对范围

仅源码核对、Release 发布编译和实际发布 EXE 启动确认。主监看首帧为 820 × 236 DIP。没有开展自动连点测试或浏览器校验；桌面自动查看工具仍未能启动，不把动画的逐帧视觉表现写成已验收。

原生接口依据：[SplitView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/split-view)、[ConnectedAnimation](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.media.animation.connectedanimation?view=windows-app-sdk-1.8)。具体尺寸、缓动与时长是本项目的选择。
